AgeWallet SDK Demo

This site hosts the app association files for AgeWallet mobile SDK demo apps.

Supported SDKs:
  • React Native
  • Flutter
  • Ionic
  • iOS Native
  • Android Native

Universal links and App Links are configured at:

  • iOS: /.well-known/apple-app-site-association
  • Android: /.well-known/assetlinks.json
